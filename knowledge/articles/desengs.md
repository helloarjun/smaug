DesEngs is an ever-growing, curated collection of resources specifically designed for design engineers. This repository brings together tools, articles, learning materials, and community resources that bridge the gap between design and engineering disciplines.

## Resource Categories

The collection includes resources across multiple categories:
- **Build Tools:** Real-time animated charts, UI components, command menus, and interactive libraries
- **Learning Resources:** Interactive tutorials, pattern libraries, and design system guides
- **Communities:** Design engineer communities and job boards
- **Articles & Guides:** Best practices and technical writing on design engineering

## Key Resources

The featured collection includes:
- **Liveline** - Real-time animated line chart for React
- **Devouring Details** - Interactive reference manual for interaction-curious designers
- **UI Playbook** - Documented collection of UI components
- **⌘K** - Fast, unstyled command menu React component
- **Web Interface Guidelines** - Non-exhaustive list of details that make good web interfaces
- **Design Engineer Jobs** - Job board for design engineering roles
- **soundcn** - 700+ curated UI sound effects
- **Design Engineering Club** - Community for design engineers

## Why Bookmarked

DesEngs represents an excellent curated reference for anyone working at the intersection of design and engineering, providing practical tools and inspiration for building high-quality interfaces with both aesthetic appeal and technical rigor.
